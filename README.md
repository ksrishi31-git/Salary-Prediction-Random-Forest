# Salary Prediction Using Random Forest Regression

## About the Project

This project uses Random Forest Regression to understand the relationship between job grade and salary.The model is trained using salary data and learns how salary changes with job grade. It then predicts salaries for unseen data and visualizes the results using graphs.I built this project to understand machine learning concepts, including data preprocessing, model training, prediction, and visualization.

## Technologies Used

- **Python** – Programming language
- **Pandas** – Loading and handling the dataset
- **NumPy** – Numerical operations
- **Matplotlib** – Visualizing the data and predictions
- **Scikit-learn** – Training and testing the Random Forest Regression model

## How It Works

1. Load the salary dataset using Pandas.
2. Separate the input variable (job grade) and target variable (salary).
3. Split the dataset into training and testing sets.
4. Train a Random Forest Regression model using the training data.
5. Predict salaries for the test data.
6. Visualize the actual data points and predicted salaries.

## Model Used

**Random Forest Regression**

Random Forest Regression uses multiple decision trees and combines their predictions to estimate the target value.It can model complex, non-linear relationships between input variables and salary.

## Visualizations

The project visualizes the actual salary data and predicted values to help understand how well the model performs.

## Dataset

The project uses a CSV file containing job grade and corresponding salary values.
The dataset should include the input feature used for prediction and the corresponding salary or CTC values.

- Training a machine learning model with Scikit-learn.
